### Hey, I'm Nathan 👋

A cybersecurity and networking enthusiast based in the UK, interested in Linux, homelabs, and how systems work behind the scenes.

I'm more interested in understanding security than just running security tools: how an attack actually works, what it leaves behind, and how you'd spot it. Most of my learning happens hands-on, through TryHackMe rooms and my own homelab. A lot of it is trying things out, breaking them, and figuring out why they stopped working.

I use GitHub to document what I'm learning and to build small projects along the way. Most of my repos are private for now while I make some changes and finish a few things on hold. I'll make them public at some point.

**Currently**
- Learning more about security, with a focus on detection and incident response
- Building and experimenting with network tools
- Developing my homelab and self-hosting more of what I use
- Turning what I learn into notes, cheat sheets and write-ups
